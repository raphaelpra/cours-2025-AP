## L'IA en informatique

### Points de discussion

**L'IA comme outil de developpement :**

- Assistants de code (GitHub Copilot, Claude, ChatGPT)
- Generation de code vs comprehension du code
- Debugging assiste par IA
- Documentation automatique

**Bonnes pratiques avec l'IA :**

- L'IA comme "pair programmer" : elle propose, vous validez
- Toujours comprendre le code genere avant de l'utiliser
- Les tests restent essentiels (l'IA fait des erreurs)
- L'IA ne remplace pas l'apprentissage des fondamentaux

**Limites actuelles :**

- Hallucinations (code qui "a l'air correct" mais ne l'est pas)
- Manque de contexte projet
- Problemes de securite potentiels
- Dependance excessive

**Le futur proche :**

- Agents autonomes pour taches repetitives
- Refactoring assiste
- Tests generes automatiquement
- Review de code automatisee

> **Message cle** : L'IA est un outil puissant, mais la comprehension des fondamentaux (ce que vous avez appris ce semestre) reste indispensable pour l'utiliser efficacement.
