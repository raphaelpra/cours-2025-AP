# Projet Python - Simulation

## Organisation

- **Groupes** : 2 a 3 personnes
- **Date de rendu** : communiquee ulterieurement

---

## Sujet

Realiser une **simulation** au choix :

- **Physique** : particules, gravite, fluides, pendules, ressorts...
- **Economique** : marche, offre/demande, agents economiques...
- **Theorie des jeux** : dilemme du prisonnier, strategies evolutives...
- **Biologique** : ecosysteme, propagation, predateurs/proies...
- **Sociale** : propagation d'information, reseaux, opinions...
- **Autre** : tout sujet impliquant une simulation est accepte

---

## Format

- **Visuel ou CLI** : le rendu graphique n'est pas obligatoire
  - Une simulation en ligne de commande avec des sorties texte est acceptable
  - Si visuel : pygame, matplotlib, terminal ASCII, etc.

---

## Livrable

Un **projet sur GitHub** executable :

- Repository public ou prive (inviter le professeur si prive)
- README avec :
  - **Noms des participants**
  - Description du projet
  - Instructions d'installation et d'execution
- Code executable via `uv run` ou apres `uv pip install -e .`

---

## Criteres de notation

| Critere | Poids |
|---------|-------|
| **Qualite du code** | Principal |
| **Documentation des problemes rencontres** | Principal |
| Fonctionnalite de la simulation | Secondaire |
| Originalite du sujet | Bonus |

### Qualite du code

- Code lisible et structure
- Fonctions et classes bien decoupees
- Nommage clair (variables, fonctions, fichiers)
- Pas de code duplique
- Gestion des erreurs

### Documentation des problemes

- Documenter dans le README ou un fichier `JOURNAL.md` :
  - Les problemes rencontres
  - Les solutions trouvees (ou tentees)
  - Les choix techniques et leurs justifications
- Cette documentation montre votre **demarche d'apprentissage**
